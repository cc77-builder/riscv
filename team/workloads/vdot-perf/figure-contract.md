# T13 性能图约定

问题：精简 RVV 与 vdot 的周期收益如何随场景、规模和预热阶段变化？图只表达实测窗口，不能由静态指令数量推断收益。

- 类型：单面板 quantitative comparison；横轴为同一轮配对的 `RVV cycles / vdot cycles`，1 表示相同，低于 1 表示 vdot 更慢。
- 数据：正式验收 `pairs.json`，13 个配置、3 个数据集；展示首次、预热和全部 4 轮正式样本。每个镜像的另两次完全一致重放在图中不重复绘制，原始 CSV/JSON 全部保留。
- 图形：按配置分行的配对比值点图，颜色和 marker 同时区分阶段；不把不同 n 连成一条时间曲线，不使用柱子遮盖离散窗口。
- 统计：展示全部配对原始比值；不画置信区间，不报告显著性。重放不是独立统计样本。轻微纵向错位只为避免点重叠，不代表第二个数值变量。
- 实现：既有 Python 分析流程与已保存的 Python 绘图偏好；Matplotlib，白底，183×160 mm，字体至少 7 pt，SVG/PDF 可编辑文字，PNG 600 dpi。
- 验收：源代码验证、单面板 alignment NOT APPLICABLE 记录、PDF 字体检查、PDF 碰撞检查及实际图片目视检查。原双缓冲区访存版本预先排除，原因与数据量在报告中列明。

图注：每个点是一次配对窗口的 RVV/vdot 周期比；大于 1 表示 vdot 更快。每个配置含三组输入、首次/预热各一轮及四轮正式测量。三次独立 EMU 重放需逐窗口一致，图中仅绘制第 0 次，未把重复结果当统计增样。窗口包含相同 fence 与循环开销，不扣除空窗口，不等同于 FU 延迟或 Fmax。
