# R5/G5 V2：firstdot 稳定源入口合同

合同 `r5-selected-firstdot-gemv-v2`，操作 `20261026-LiZufan001-r5-firstdot-0056`。
本轮把已合格 firstdot 普通 C 库提供为可迁移、可回退的四形状源入口。
它不修改硬件、firstdot 汇编/公开头、历史 R5 V1、官方程序或旧实验合同。

## 选择及兼容边界

新包只含原 firstdot 完整对象；四个 `xs_gemv_<shape>` 默认映射到
firstdot/reuse，4×8、8×32、16×64 选 vdot，4×13 选 RVV。
四个显式 `_rvv` 别名及 `XS_GEMV_FORCE_RVV=1` 均使用 firstdot/reuse/RVV。
源 API 版本为 2；仅承诺 C，宏最终展开值限字面量 0 或 1。
原 V1 的源/清单/验证器不变，切换包后调用端必须重新编译。

选择依据是已冻结 firstdot 完整矩阵的 12 正式窗/候选，包含全部合格
S1/firstdot、basic/reuse、vdot/RVV。三个 vdot 默认须优于同轮原 S1
及最快合格 RVV；K13 RVV 可在聚合并列时选择同一 firstdot 对象内版本。
实际包内 RVV 回退和公平比较的最快 RVV 分母分别记录：4×8 的
firstdot RVV 为 187.75 拍，最快 S1 RVV 为 187.50 拍，不混称为同一项。
这些是原固定计划的资格，不是新包或任意应用的新性能测量。

输入为对齐的 INT8 行优先 A 紧接 x，输出每行 16 字节（低32位结果、
高96位零），输入输出不重叠。形状、容量、RV64 lp64d、VLEN128、VS、
寄存器与返回CSR合同完整继承 `FIRSTDOT_C_CONTRACT.md` 和原 C ABI。
不新增量化、运行时分派、紧密 INT32 输出或任意 VLEN 支持。

## 验证与停止条件

1. 在新原生工作区执行冻结 firstdot C 证据器的完整原文审计，连带
   重算性能矩阵。核对源、归档、T17身份和完整对象，选择从复算数据推导。
2. 真实 GNU 构建新 `.a` 与两个可独立搬移的头文件。库中唯一 `gemv.o`
   必须逐字节等于已合格 27,416 字节 firstdot C 对象；原16函数保持。
3. 默认、显式0、显式1三种配置覆盖全部8别名；与显式 firstdot 调用的
   完整 caller.o 和可重定位链接产物逐字节相等，并检查实际未解析符号。
   `ld -r` 的 exit0 本身不代表符号已解析。
4. 测试非法开关、宏展开0/1、版本选择、V1/V2头包含顺序与错库配对。
   V1先包含后V2拒绝；V2先包含后冻结V1被共同guard跳过，仍保持V2。
   统一一个翻译单元的头版本不能代替跨翻译单元的完整重编译。
5. 在脱离仓库的搬移包上实际编译/链接文档调用者，验证输出对象、库成员
   与叶函数身份；缺头/错库等负控须明确失败。原V1验证器用于确认回退入口
   仍可使用，输出只写新目录。
6. 新增检查器对重哈希后的错误别名/错误选择或错误库仍须拒绝，不能仅
   依赖文件哈希识别参数错误。独立审查并保存命令、退出码、原始输出。

本合同不重复已合格33次性能和3次C执行。保持同一完整对象、原资格与
别名/显式调用等价时，新增EMU为0；不宣称新最终ELF、应用周期或人工验收。
若实现改变leaf、混合对象或运行时wrapper，停止此薄入口资格，另按真实
影响确定新运行合同，不能事后放宽上述要求。总CPU最多4，最多两个独立
GNU验证worker，库构建 `-j1`。所有结果置于仓库外新目录，失败原样保留。
