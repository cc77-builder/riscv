1. 画出接受、存储、输出、反压和取消的周期合同，覆盖空队列、满队列、同拍出入、分别取消、异常、VDot/DIV切换和真实门控。

   1ns只是现有参考约束，不是官网硬门槛，也不代表旧版已经收敛。
4. 保留吞吐II=1及两槽能力，明确每一项行为/元数据/写回身份必须保持的验证。

## 成功后才进入的验证顺序

提前向用户说明具体RTL文件、信号、行为变化及合同 → 局部算术/队列模型与FU →
真实VFEX4父级（DIV切换、反压、取消/复位/门控） → 同约束综合与五档STA →
符合预先门槛才全核NEMU/完整128位差分 → 同镜像周期 → 必要接入/复现。
没有通过前级就不启动昂贵后级；失败保留、无自动重试预算。

若未来选择改共享写回/唤醒路径，必须另立最小WB/IQ/OG身份观测合同，先补动态证据。
当前五拍聚合观测不足以指定某一拍可删除，不能与VDot内部短延迟候选混做。

## 条件估算，非跑分

现有每窗1857 = 37 + 255×7 + 2 + 33。
仅假设FU2→1、后端五拍及首尾边界均保持：37 + 255×6 + 1 + 33 = 1601 cycles。
这对应13.7857%周期下降、约1.1599倍相对当前chain256，**不是候选实测、保证值或普通C/GEMV收益**。
仅假设后端五拍减为四拍且FU不变，模型是1602；两种假设不能混用。
若时钟周期增长约15.99%，第一种模型的处理时间收益就会抵消；本项目没有整核Fmax实测，不能拿父级STA代替整核频率。
