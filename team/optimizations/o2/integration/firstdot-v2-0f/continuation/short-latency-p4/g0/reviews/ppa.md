**建议：GO，仅进入有界的独立候选局部实现与同约束成本筛选；当前 NO-GO 于采用候选、重建全核或宣称性能提升。** 一拍算术逻辑在结构上可定义，既有组合算术单元可复用。主要风险是乘法和归约连为一条组合路径，以及新结果直达 R 带来的宽身份包选择。面积与时序是否划算目前均为 NOT_TESTED。

## 1. 固定唯一候选，避免增加无关变化

基线为 0f 的 O2 两槽 + H1 低32位保存 + DIV 取消关钟修复。候选保留 P/R 两槽、已有 ready/取消/父级排他语义；P 改为32位已完成结果。一个共享的组合点积计算输入结果；无 liveP 且 R 可接收时，新包直接在当前边沿写 R，否则进入 P；旧 P 迁入 R 的优先级高于新输入。R 的对外输出仍只来自寄存器，不新增算术到输出的组合直通。没有 liveP 的稳态空队列接受后，最早下一拍响应；反压时仍可保存两个请求。

本轮不选环形队列、不更改父级 DIV 控制、不加入预测唤醒，不裁剪 ctrl/perf 字段，不顺手改算术精度、综合选项或非法配置语义。

当前源码依据：

- VDotDatapath.scala:17–20：8 个 signed int8 × int8，产物16位；
- 同文件34–48：4×17、2×18、1×19的平衡归约，符号扩展到低32位，高96位清零；
- 同文件55–68：现有无时钟组合顶层已把上述两块直接连接；
- VDotElastic.scala:38–51,76–80,94–107：当前P保存8×16位乘积，下一边沿归约写R的32位结果；
- 同文件57–74,85–92：非法配置、两槽取消、ready和保存后的身份/结果输出。

以上路径统一以仓库 src/main/scala/xiangshan/backend/fu/ 为前缀，完整绝对路径和逐行摘录见 source-excerpts.txt。

## 2. 算术宽度和组合路径

8路乘积范围为[-16256,16384]；8路和范围[-130048,131072]，需要19位有符号数。最大值131072不能装入18位有符号数。必须保留现有逐级扩位和最后符号扩展，不能为了短路径把中间结果收窄。取两源的低64位，高64位忽略；非法配置写回异常、关闭写使能并输出零，仍按当前协议完成/取消。

当前两条路径：

1. 源输入 → 有符号8×8乘法 → P乘积寄存器；
2. P乘积寄存器 → 17/18/19位归约 → 非法结果选择 → R结果寄存器。

候选合并为：

源输入 → 8×8乘法 → 三层扩位归约 → 非法结果选择 → P/R写入选择与保持 → 32位结果寄存器

一层加法不是一个门延迟；实际进位结构、映射共享、负载、缓冲和输入到达时间由未来综合/STA决定。新乘加结果同时服务P/R输入，必须检查扇出与复制，不能无意生成两套完整乘加。输入ctrl/perf还需在“旧P包”和“当前输入包”之间选择，虽然算术不在meta路径上，选择信号和宽多路器仍可能成为新关键路径。保留R输出可避免环形缓冲的全输出选择器，但不能保证输出、ready及门控路径因整体映射而不变。

组合算术旧验证 team/rtl/vdot/README.md:5,7,71 只证明22组定向+10000组随机的数学结果。其仿真没有时钟，不证明一拍时序，也不证明候选FU正确。

## 3. 面积：能省多少寄存器，不等于能省多少面积

从既有 fu-map-01/mapped.json 精确选择 CommonFuCostTop，按每个DFF的Q bit及dut.*寄存器别名分类；8组不交叠，联合覆盖全部1742个DFF_X1，结果如下。

| 分组 | 现有映射DFF | 唯一候选的声明层预期 |
| --- | ---: | ---: |
| P算术数据 | 128 | 32 |
| R结果数据 | 32 | 32 |
| P ctrl | 213 | 213，必须保留 |
| P perf | 577 | 577，必须保留 |
| R ctrl | 213 | 213，必须保留 |
| R perf | 577 | 577，必须保留 |
| P/R valid | 2 | 2 |
| 合计 | 1742 | 1646，**结构模型，未经映射** |

若其余部分相同，数据寄存器仅减少96位。Nangate45典型库DFF_X1面积4.522 μm²，裸DFF理想差值434.112 μm²，约基线FU面积的2.509572%。**不能把它写成候选节省面积：** 两份身份仍占1580位；R写入“旧P/新输入”的选择会增加多路器及控制、缓冲，可能抵消全部寄存器节约。库内MUX2_X1为1.862 μm²，但不能将“位数×MUX面积”当成实际映射，因为映射共享/优化和保持结构会变化。

独立FU保留完整端口，比父级实际使用范围更大。父级已经裁剪部分元数据，历史STA绑定到VDot的寄存器数为1352；不能把独立FU的96位节约直接加减父级总面积。父级面积包含FU，也不能把两者相加。

## 6. 周期收益不能自动抵消时序代价

历史P2证据为ACCEPT→RESPONSE=2、邻接依赖接受间隔=7。若只把FU内部变为1拍、其余5拍反馈/窗口前后开销均不变，则chain256有条件模型为1857→1601 cycles，约节约13.79%，周期比1.159900×。这些是假设下的模型，不是新跑分；候选内部变1拍也不保证整核邻接间隔一定6拍。

即便将父级代理5%上限当成假设时钟增长，模型链路仍可保留约1.10467倍物理时间收益，但**没有资格据此宣称真实时间提速**：代理不是整核时钟，且吞吐型batch原本已可II=1，缩内部延迟未必降低batch周期；若真实时钟变慢，batch可能退化。因此进入全核之后仍须比较chain、batch、single、stream及稳定firstdot/C8调用，分别报告cycles、周期加速比与时序限制；不能用一个链路项目替代全项目采用判断。

## 7. 采用边界和复现记录
