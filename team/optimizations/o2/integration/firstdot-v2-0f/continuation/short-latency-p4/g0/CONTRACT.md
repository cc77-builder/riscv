未来实现建议用独立实验输出和编译期默认关闭的候选开关（拟名 `VDOT_P4_ONE_CYCLE`）；只接受0/1，要求 O2/T14 合法组合。关闭时保持原功能生成物。不得让新候选使用旧两拍观察器冒充有效轨迹；G1 独立适配 FU/父级测试观察，G3 才适配全核观察器。具体修改前仍须向用户说明文件与信号。

## 2. 状态转换合同

沿用 killP/killR、liveP/liveR、rReady=!liveR || out.ready、move=liveP && rReady、pReady=!liveP || rReady。所有以下值取时钟沿前状态：

    accept = in.valid && pReady && !flush.valid && !reset
    pop = liveR && out.ready
    directR = accept && !liveP && rReady
    toP = accept && !directR
    nextPValid = (liveP && !move) || toP
    nextRValid = (liveR && !pop) || move || directR

move：旧 P 的 data32/完整 ctrl/perf 同沿写 R。
directR：新 data32/完整 ctrl/perf 同沿写 R。
toP：新 data32/完整 ctrl/perf 同沿写 P。

move 与 directR 互斥。输出只来自已有 R，不从输入或 P 组合穿透。一次可同时旧R响应、旧P搬移、新请求进P；占用上限2、连续独立流 II=1，吞吐能力并非从2拍变成翻倍。

取消逐槽按完整 ROB 代际计算，不能假设接受顺序等同 ROB 年龄。无论 flush 是否命中，flush 当拍都不接收新输入；未命中的 R 仍可正常响应。命中 R 而 P 存活时，只在沿上把 P 搬 R，不让 P 当拍从输出旁路。复位有效时禁止接受和响应；valid 清零，旧无效载荷无需物理擦零。被反压的响应只有命中取消或复位才可撤回；否则所有输出字段保持。

非法输入同样占槽并绑定原身份；输出数据为零、illegalInstr=1、vecWen/v0Wen 均关。合法写Vec/V0互斥协议、vpu/perf完整保存、其他输出副作用均与0f一致。别名、符号和高96位不能仅靠低32数值检查替代。

父级继续读取沿前 raw pValid/rValid；不把 kill 后的瞬时空闲当同拍 DIV 切换许可。保留真实子DIV ready、busy、out.valid、取消保持位和逐FU门控。VDot 最后一条释放与 DIV 新接收仍遵守原跨拍隔离。这些方程是设计合同；抽象模型通过不等于 RTL 或真实父级通过。

## 3. 组合路径与成本边界

当前：输入→乘法→P寄存器；P→平衡加法树→R寄存器。
候选：输入→乘法→三层扩宽加法→非法结果选择→P/R写入选择→结果寄存器。另检查 ctrl/perf 的 directR/move 选择、flush/ready 到写使能、输入高扇出与父级输入选择。

保留 R 寄存输出，不把乘加放到写回输出组合锥。不能把旧 input→reg 与 reg→reg 两个到达时间直接相加，充当新 STA；映射、驱动、负载和终点均变化。

0f 指定 FU 映射共1742 DFF：128乘积＋32结果＋2×213 ctrl＋2×577 perf＋2 valid。候选载荷160→64，若其他不变只少96 DFF。以该库 DFF_X1 4.522 μm²算，裸寄存器差434.112 μm²（旧 FU 的约2.51%）；新增选择器/缓冲/映射变化未扣除，**不是净面积预测**。两份身份不能删除。

0f成本：FU 17298.246 μm²；含FU真实父级 284614.946 μm²。名义父级全局最差 setup slack −2.393998 ns，参考周期1ns；基线不满足1ns，不能写成流片时序闭合。库/版本/约束见 reviews/ppa.md，新候选面积、STA、频率、功耗均为 NOT_TESTED。
