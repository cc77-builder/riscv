## P0最重要的发现

供体split的74.5%来自“旧wrapper每次复制全部288B”的指定夹具。当前C8测试数据原本已经连续；真实runq权重固定、激活单独产生，且可以复用权重准备。因此不把每次复制A当成合理C8的必需成本。

本轮将公平对照确定为三种独立窗口：

| 窗口 | C8/packed待遇 | split待遇 |
| --- | --- | --- |
| steady：主指标 | A只准备一次，每次更新32B x；计算＋128B槽＋INT32提取 | 直接读分离A/x，完成相同计算与输出 |
| first：首次准备成本 | 计入一次256B A准备、32B x更新及完整调用 | 从同样已形成的A/x tile开始完整调用 |
| native：已连续输入 | 不加任何额外复制 | 指向同一连续输入的两个不重叠子区间 |

first不是冷cache；3个窗口不互相拼分母。当前还没有在0f上运行真实runq/QKV，本轮确认的是使用结构和最小接口需求。
