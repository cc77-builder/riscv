# 当前0f硬件的普通C接口范围

本地外层合同见[验证合同](tools/c8-v2/CONTRACT.md)，原内层r2-s3-config-reuse-c-application-v1的门禁保持；旧T17身份由本轮固定clean-02身份明确替代，没有转借旧资格。

8×32输入为行优先INT8矩阵A（256字节）紧接INT8向量x（32字节），共288字节。输入/输出各自16字节对齐、完整且互不重叠；8行输出各16字节，共128字节，每行低4字节为INT32结果，高12字节为零。本轮实际运行环境为Nexus-AM裸机C程序；需要RV64 lp64d、VLEN128、VS已启用，vdot函数需当前自定义编码支持。向量状态/寄存器及ABI允许的调用者保存寄存器可以被覆盖。以[真实C程序](public/main.c)和[源表](public/manifest.json)为本轮已执行用法。

16个函数完成公共C功能验证；只有8×32 reuse vdot沿用本轮矩阵的性能候选结论，其他形状不据此升级。未创建静态库或dispatcher，未切稳定默认；普通C程序不提供新性能样本。
