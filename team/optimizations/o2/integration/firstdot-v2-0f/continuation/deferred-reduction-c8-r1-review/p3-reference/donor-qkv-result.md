# 实际 FP32→QKV 目标结果

合同 `r2-s3-runq-active-qkv-target-v1`，对应[完整验收条件](CONTRACT.md)。本批从通过活动 forward 的层0、位置0/1取得真实 FP32 激活，用共同的量化器和 Q/K/V 包装比较 TA 与 FR。两路复用已合格的完整投影机器码，最终 ELF、数据布局和计时计划是新的独立身份。

**真实负控、正常恢复、独立重放和封存新源复算均已闭合。按事前规则，本固定 FP32→QKV 计划显式选择 TA；保留同接口强 FR 回退。最慢 TA 相对最快 FR 少 3.4731903% 周期。**

## 使用与范围

[普通 C 接口、回退和复验命令](../README.md)可以接入 `qkv_boundary`。调用方显式选择 `q288_tail_vdot` 或 `q288_fused_rvv4`，使用现有去重内核导出及独立的 `boundary.S` 对象。新链接仍需按其实际地址、布局和调用条件验证，不迁移这里的周期数字。

本计时包含 FP32量化＋三个预打包投影及调用返回，使用共同标量量化器。pack、RMSNorm、RoPE、attention、KV写入、FFN、classifier与完整token不在窗口内；不声称最优RVV量化。确定性未训练权重不能给出模型质量结论。完整宿主活动状态接续单独成立，不等于在目标机执行了完整模型；R5稳定默认、生产RTL和历史结果均保持原资格。
