# full-Q 行间向量 FP 融合：静态筛选合同 v1

合同 `r2-s3-runq-q288-fused-screen-v1`。本阶段不启动 EMU，不变更稳定入口或性能选择。目标是对后续完整 Q 候选作真实 GNU 编译、实际机器码数值/地址验证和有界成本筛选。

## 新边界

新增 `q288_fused_vdot` 与 `q288_fused_rvv4` 两个完整 288×288/GS32 入口，接受原 `q288_context` 的前六个指针；第七个 `entry` 字段保持但不读取，整数方法由函数符号明确选择。它们是独立消费者，不是旧 split 叶的等价重定位。既有公开库、六个冻结叶、acc8 包装和正在执行的 target-v1 输入均保持原样。

允许在函数内部融合全部 tile/group 循环。每组保留固定团队 vdot/RVV4 算术及其重置，删除每组普通函数调用、重复 CSR、ABI搬运和中间槽落存。仅在全 Q 末尾写最后一组的八个完整 128 位槽，保留可观察结果；不承诺中间槽值。不得改变官方源或参考模型。

## 数值和 ABI

VLEN128，FS/VS enabled、FRM=RNE；quantized byte 指针可任意字节对齐，float 指针4B、slots16B对齐，各区间不重叠。保持 P[t,g,r,k] 与原 row-major Ws/Xs 布局。

整数 core 不写 v8…v15。v8–9 保存八行 FP32 累加，v10–11 收拢八个低32位整数，v12–13 读取 stride36 的八行 Ws。收拢在 vl4/e32/m1 进行，每半采用一次 vmv 与三次不重叠 vslideup；转换/两次乘法/加法在 vl8/e32/m2 进行，严格保持每行 g0→g8 的 `(float(dot)*Ws)*Xs` 再加顺序。禁 FMA、预合并尺度和跨组整数累加。

每条自定义 vdot 仍严格为 e8/m1/VL8/vstart0，完整高96位归零；RVV4 的 e16/m2 reduction 后先切 e32/m1 再收拢。返回 vl8/vtype0/vstart0/vcsr7，全部整数/FP callee-saved 和 sp 保持。只使用 caller-saved 标量寄存器、ft0 与向量寄存器，不分配栈。浮点异常标志允许正常累积。

## 筛选门禁

1. 真实 GNU 编译、真实 ELF 全字编码；以独立的机器字允许列表核对从固定团队整数体提取的算术、重置、寻址和删除边界。
2. 实际完整函数执行的有限数值模型必须逐位匹配独立 row-major C/Python golden，覆盖 x0→x1→x0→x2、−128×−128、127×127、混合极值与全零权重；保留原 FMA 见证。模型不是 CPU、NEMU、目标 DiffTest 或周期模拟器。
3. 完整检查实际路径、324次连续整数核、每组向量模式、signed 转换、收拢顺序、Ws/Xs 地址、输入只读、全部288输出、末组完整槽、callee-saved/栈与CSR。模型入口使用非目标 CSR 状态，检查真实重置。实际 ELF 的错误转换、收拢、尺度地址、累加源、callee-saved、缺失 CSR 重置及保持操作总数的两乘法顺序交换必须被拒绝。
4. 以同一完整 Q 边界和冻结计时协议计算静态指令：两种方法相对 acc8 各至少减少5%，且不存在新增栈spill、非法重叠或遗漏工作，才允许进入独立的目标合同。5%为本阶段研发门槛，不是比赛标准或实测性能阈值。

vslide 的旧目的依赖、stride load 微操作、浮点流水和类型切换均可能抵消架构指令节省；不得把静态百分比当加速。通过本阶段仍需新的目标完整输出/架构 DiffTest、同 BIN 实际负控→恢复→重放，以及另立的公平比较条件。原六叶或 acc8 的历史 PASS 不自动授予新路径。

数值模型限定 RNE 的有限值及有限结果；单独与实际本机 C 比较 int32 转换、binary32 加法和乘法，覆盖舍入、次正规数与负零。NaN/Inf、溢出到无穷、异常标志及非RNE不属于此模型证据。前四次调用保持同一模拟 packed 地址/存储并继承向量寄存器状态；其余极值用例覆盖额外字节对齐。静态比较以真实完整函数体为主，同计时器的加16条投影单独标注，不冒充新候选计时器的实际执行。

旧 8×32 优先规则在这里由已确定的实际完整 Q 消费者边界细化；既有小形状合同仍约束其原版本，不为满足旧内部调用形态保留无价值的中间存储。
