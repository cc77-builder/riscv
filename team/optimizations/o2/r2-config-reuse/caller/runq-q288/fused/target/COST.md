# Q288 融合后的 FU 边界与消费者位置诊断

状态：**Q288_COST_DIAGNOSTIC_PASS**。这是对已闭合 [fused-target-v1](RESULT.md) 的原始轨迹作出的新离线观察；没有新增 EMU、硬件改动或性能资格。第一次实际分析为 2026-10-26 12:35:37～12:35:55（UTC+08:00），单 CPU。全部 12 个计时窗、原 CSR 样本、真实 ELF 退休路径及全阶段 custom 身份均闭合。

**直接结论：本固定计划的融合 vdot 没有 FU 出口背压，也没有超过固有两拍的 FU 内驻留；值得优先检验上游软件排程。现有观测不能把间隔单独归因于配置、载入、缓存或 FP，也不能换算为可消除的周期预算。**

## 1. 实际观测

每个 AV/FV 窗有 10,368 笔唯一的完整事务。下表使用 cycle CSR 采样区间，不使用 marker 间隔替代计时。AV 是原 acc8-vdot，FV 是当前 fused-vdot。

四个 vdot 窗的父接口 WAIT、DIV、未绑定额外 ACCEPT、KILL 均为零；目标事务没有跨越计时边界。两 FV 窗的 P/R 零占用分别为 47,600 / 47,594 拍，一槽为 9,446 / 9,460 拍，两槽为 5,645 / 5,638 拍。这里的空闲范围仅为 VFEX4 的 VDot/DIV 观察域，不是整核或全部向量执行单元。

FV 全窗平均接受密度约 0.16538 条/拍，相邻接受时间间隔中位数 1 拍、p90 为 13 拍、p99 为 44 拍。最长连续逐拍接受为 4 条；同拍 RESPONSE/MOVE/ACCEPT 分别出现 2,823 / 2,822 次。因此短区间确实用到了 II=1，但完整 Q 并未持续供给该接口。

`response→commit` 均值为 3.7906 / 3.7969 拍，中位数 2 拍，最大 33 拍。这是响应之后的退休等待，不能叫作写回背压。没有额外 FU 内驻留也不证明缩短固有两拍延迟永远无收益。

ready 周期和静默周期分别保存。静默依据实际 T17 源码发射条件只能证明 P/R 无效、DIV 未占用、父输入无 valid、无 flush，不补造 ready/outready。重叠事务等待按周期并集计算，不将每笔等待时间相加。

一个有用的反例来自真实结果：FV 的直接 ready 等待周期比 AV 更多，但完整 Q 更快。因此这个诊断量不能替代应用周期排名，也不能直接当成可消除的成本。

## 2. 324 个动态组的位置

每窗按实际 PC/word 路径关联 324 次整数 core，每组 32 个 custom。FV 两次观察中，每组首 ACCEPT 到末 RESPONSE 的包络均值为 149.9475 / 149.9815 拍；一组末 RESPONSE 到下一组首 ACCEPT 的均值为 42.8390 / 42.8080 拍。这些包络包含与载入、配置、归约、FP 消费和控制的重叠，不是纯 vdot 或可直接删除的间隔。

按程序顺序，dot 8→9 的接受时间差均值约 25.02 / 25.04 拍，dot 16→17 约 22.71 / 22.75 拍；其他跨归约/配置/载入的边界约 11～12.5 拍。同样含模式切换的片段并不具有相同时间差，现日志缺少所有源操作数 ready 和 issue 事件，不能据此声称“vset 每次固定阻塞多少拍”。

324 组中只有 282 / 279 组严格按程序顺序接受，其他组出现合法乱序接受。原始分组结果保留带符号的相邻时间差，不把负值截为零，也不把调试 seq 当作程序次序。

FV 的整数 core 末退休到 FP 转换退休平均为 30.4383 / 30.4691 拍，转换到组内 FP add 退休平均为 22.0278 / 22.0123 拍。它们是退休前沿坐标，可能受更老指令与乱序重叠影响，**不作为 FP 执行周期或独占成本份额**。AV 的记录边界是完整叶函数，FV 的记录边界是融合体内整数 core，两者也不能直接当成同边界的局部性能比较。

## 4. 路线决定

当前证据不支持为解决出口拥塞或增加容量而改 FU。更有依据且投入较小的下一步，是仅对已通过静态筛选的 [phased](../phased/RESULT.md) 做一次独立目标对照：保留当前 FV 和最快 FR、同 ELF/同预热、两个反序块和全部锚点，直接检验配置 12→4 的收益能否抵消延后 add、更多 partial 存活和寄存器压力的代价。

这是一个可证伪的软件排程假设，不是已证明的 vset 瓶颈或新性能收益。若新候选没有通过预定保守门槛，保留当前融合入口与强 RVV，不连续枚举。新合同仍须真实 ELF/数值/负例检查、DiffTest 拒错恢复及独立重放后才能产生自己的结论。

本诊断仍限于固定合成、预打包 Q；没有 pack/量化/token/完整模型、模型质量或 ASIC PPA 结论。R5 默认、旧 HOLD 和全部回退不变。
