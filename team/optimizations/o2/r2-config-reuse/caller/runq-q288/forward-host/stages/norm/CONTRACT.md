# RMSNorm 保序输出 RVV：有界工程合同 v1

冻结前基点：`431938271dd3b9eda8595a45d2bcf4e429d25797`。本合同为团队新增实验，不修改官方程序、上游原文、旧实验资格或 R5 默认。

## 假设与候选

固定模型每个 forward 有 13 次 size=288 RMSNorm，最后一次原地 `o==x`。只把输出 `weight[j] * (ss * x[j])` 的两次独立 binary32 乘法向量化；逐项平方/标量左折叠、除 size、加 epsilon、sqrtf 和倒数严格沿原源码。真实 C 调用中的全部成本（含配置保存/恢复和调用开销）进入计时。不是在缺乏证据时断言 norm 为全模型瓶颈。

调用域：RV64/lp64d、VLEN128、RNE、FS/VS enabled、vstart=0；size=288，4B 对齐有效数组，输入/权重有限（含 ±0、次正规），输出可以溢出；weight 始终与输入、输出 span 分离且不可写；输出与输入相同，或二者 span 不交叠。保持 frm/errno、sticky fflags 和 vcsr；恢复原 vl/vtype。按普通 C ABI 向量寄存器可破坏。禁止 fast-math/FMA/reassociation。不声称支持任意舍入模式、非有限输入、任意重叠或并发重绑定。

## 输入及功能验收

固定原样 runq.c 和原确定性模型，捕获 token 1/7/19、p0..2 的全部 39 个真实 norm 前后输入、权重和输出；带捕获的 forward 完整状态须与原 forward 及已有 host gold 逐字节一致。额外固定零/负零、次正规、平方溢出、输出溢出、左折叠敏感和输出舍入敏感用例。每个用例标量与 RVV 均覆盖独立输出和 `o==x`，清零与预置 NV|DZ 两种 flags；比较全部 288 输出、完整输入/权重、guards、fcsr/errno 和向量配置。预置 flags 只检查保留及逐位相同，不代表输入本身触发 NV/DZ。

先用原 NEMU 完成同 ELF 的负控、正常、独立重放；再用固定 T17 EMU/原 DiffTest 完成实际输出末字节翻位负控、正常恢复及独立重放。只有正确性完整闭合才进行性能取舍。退出必须为正确 rs1=a0 trap，实际拒错代码和最后字节位置精确检查。

## 目标计量与事前取舍

正式边界是 p2 的 13 次完整 norm 调用，输入/输出为独立缓冲区，最后一项保留原地调用。每个样本先同方法执行一遍完整 13 项并检查，再恢复全部输入/输出、配置/flags，计量整个 C dispatch 的 13 次调用。顺序 `S,V,V,S,V,S,S,V`，两组 ABBA/BAAB；各 4 个正式样本。UART、比较、fixture恢复在窗口外；调用、平方、归约、sqrtf、倒数、两乘法、末次原地成本均在窗口内。重放不扩增正式样本。

四个 S 窗口 max/min−1≤1%，V 最慢相对 S 最快至少少 0.5%，且两个顺序组均有利 V，才授本固定边界的可选 RVV 性能资格；否则保留 scalar 或 HOLD，保留全部样本，不事后改门槛。完成周期、instret、全部四 CSR 的实际 ELF/退休/采样链与终态核验。该 ELF 无 vdot，不把旧 custom 事务计数或完整普通退休假作新验证；原 DiffTest 一直启用。

预算：构建/参考及目标共享总 CPU≤4；最多三个独立 EMU，各单核，输出/进程组独立。参考每进程 100M API/300秒；目标每进程 4M guest-cycle/3600秒/512MiB 单原始日志。负控先行，正常/恢复/重放可并行。达到预算即保留失败并收束，不以完整前缀判 PASS。若取得边界收益，再复用相同对象派生纯 consumer，验证全部 state/模型与原回退；新完整参考不等于完整香山 forward/token 资格。
