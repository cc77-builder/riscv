# R2-S3 split-input 8×32：独立接口与有界调用实验

合同：`r2-s3-split-input-8x32-v2`。源码基点
`71b24fc43a7111abae1012d0c4bcaf89f249300f`。本合同在v2首次构建前固定。
旧 caller/hoisted 合同和 HOLD 原样保留；不更改 R5、RTL、官方程序。

v1的真实功能输出为84调用/6负控通过；运行中19/252窗已到1,964,005拍，
最近每窗起点间隔约31,500拍，原300万拍预算与框架工作量不匹配。
v1原合同、源码、构建和运行原文保留，最终退出状态单独记录，不作性能取舍。
v2只改窗外框架：独立C标量golden从只读输入预计算一次（7×8×32项）；
用真实union成员实现对齐64位填充/比较，覆盖完整768B arena和288B packed，
全部slots/y/guards/CSR仍逐调用检查，六项实际故障控制保留。
不存在校验和或抽样。GNU C11 union访问、尺寸/偏移/对齐有显式静态断言。
每次调用仍重置全部实际输入和输出；reference只在dataset/layout切换时准备。
84功能、252窗、conditioning、次序、锚点、采用门槛和300万拍上限全部延续。
窗外代码和链接布局变化形成新的实验身份；只比较v2内的数据，不混入v1部分窗，
也不据此解除既有hoisted HOLD。

## 假设与修改范围

现有普通 C 消费者已有分离的 A[256] 与 x[32]，却因两参数 leaf 要求
A||x，每次复制288字节。本实验增加 `(A,x,slots)` 三参数叶和
`split_full` 包装，保持原算术、CSR、完整128位槽及INT32提取。
新旧配对的函数长度相同：只将两个参数搬移重排为先保存a2到a3、再令a2=A；
x保持a1，只将原A+256/264/272/280改为x+0/8/16/24。
最终ELF必须逆向还原为已固定的旧完整函数字节，禁止其他机器字变化。

六类算法为config-reuse/reuse vdot，以及上一hoisted合同的全部五类
不同RVV机器码。每类都有新旧接口；各接口内vdot/RVV共用同一包装，
packed与split各用对应包装，输入、工具与硬件相同。
普通函数指针类型正确，不把三参数函数强转为旧两参数类型。

## 平台、接口与功能验收

固定T17身份SHA256 `4a89872d0463163ea0be83f680843352e01354043f5709509d822353221258eb`；
GNU11.4、原nexus-AM与正常参考/flash/EMU只读复用，运行前后验证实物。
RV64/lp64d，VLEN128，VS已启用。无新时钟、复位或RTL接口；原两槽VDot的
首响应2拍/无停顿II=1属于已有硬件合同，本轮不据此声称应用周期。

A为行优先8×32个有符号INT8，x为32个INT8；均可按字节非对齐，至少各256/32B。
slots按16B对齐，八个16B槽，每槽低32位为精确INT32累加、高96位零；
y为八个INT32，满足其自然对齐。A/x/slots/y/context互不重叠且生命周期有效。
返回VL8/e8/m1/tu/mu、vstart=0、vcsr=7；向量寄存器/配置按原合同破坏。

必须验证：六类原函数与新寻址完整机器字证书；实际VL/EEW的向量读取足迹；
A/x只读；完整128B槽与32B y写覆盖；split路径不访问旧packed区。
真实C测试七数据集（原三组、全-128/全127/混合极值/零），两种非相邻且
A/x地址顺序互换的非对齐布局，全部六类共84次调用。独立标量oracle、输入/空隙
原字节、完整高位、所有guards/未使用区与返回CSR必须通过；完整64位比较等价覆盖
每个字节而非只比较摘要；连续调用覆盖七组数据，
每次重置输入及毒化输出。
至少六项实际故障可被C判定器检出，并从最终ELF独立推导退休路径及计数器顺序。

每个新BIN执行一次实际vd0 bit100负控、同BIN正常恢复和独立正常重放；
重放逐窗口一致，仅验证稳定性，不扩充统计样本。保留失败现场，不盲目续跑。

## 单镜像完整调用测量

仅一个新ELF，链接旧六类、新六类、未改hoisted包装与新split包装；
同一个assembly计时器按传入函数地址调用对应包装。完整窗口包含指针捕获、
栈保存/恢复、真实间接leaf调用与INT32提取；旧接口额外包含288B复制。
context设置、方法选择及共同conditioning在窗外，双方相同。
所有计时结果行延迟到矩阵结束；BEGIN和FUNCTIONAL状态行在矩阵开始前输出。
窗口之间只保存定长记录并执行统一检查，不输出UART。

三个原数据集，每集六轮（首轮/预热/四正式轮），每轮十二方法各一次，
偶数轮正序、奇数轮反序；每轮前后各测一次同一split-vdot锚点。
共252窗，普通方法216窗/144正式窗；锚点36窗/24正式窗，单独统计。
每窗前共同执行一次split/firstdot-RVV全调用，再统一重置数据/guards/CSR，
该conditioning不计入被测窗。不能声称其使微架构状态完全相同。
首次、预热与锚点均不并入普通方法正式均值。

**接口采用门槛：** 六类各自split相对同镜像packed的12正式窗总周期至少减少5%，
且每数据集四窗总周期不退化超过1%；正确性全部通过才授予可选接口资格。
不要求选择唯一最快算法才交付接口，不改R5默认。
**内核筛选门槛：** 每数据集内，正式锚点按首尾×正反序形成四组（各2窗），
其总周期max/min−1≤1%，
否则保留HOLD_CONTEXT_VARIATION与全部显式入口。通过后按五类split RVV
12窗总周期最小者作对照，vdot须在数据集×正反序六格（每格2窗）各至少少0.5%才建议vdot；
否则保留RVV/显式选择。最低观测行不等于全局最优。
不根据结果放宽门槛、增加采样或删除较快RVV。
