# R2-S3：8×32 普通 C 消费者与成本测量 v2

合同身份 `r2-s3-caller-8x32-v2`；源码基点 `e4cabff10fb3b950eab77cc6293d7f070814c188`。

v1 的首个正常进程在200万拍上限处完成139/144窗口后被拒绝，未取得运行或性能资格；其源码、产物与原始日志独立保留。v2只把窗口外重复的UART文字改成 `CW seq cycles instructions`，并采用300万拍资源上限。全部窗口、输出判定、负控/恢复/重放和计数器合同保留；不混用v1/v2周期，也不把测试输出压缩记为GEMV性能收益。官方AM及其UART实现保持原样。

## 目标与停止条件

已有 `RUNTIME_README.md` 的栈版 `gemv8(A,x,y)` 只完成过编译链接。本子项实际运行该示例，并在单个 8×32 形状上测量有完整输出可检查性的普通 C 消费入口，判断打包、内核调用和提取成本。不是新 RTL 候选，不重复旧四形状矩阵，不承诺必须找到额外加速。

先完成 GNU/静态路径与判定器拒错，再进行一个新 ELF 的负控、同 BIN 正常恢复、独立正常重放。三组既有数据放入同一 ELF，避免每个数据集分别启动一套恢复链。所有主指标和诊断都必须正确、计数器经过硬件核验且整窗重放相同；否则停止性能判断，保留失败。该固定范围完成后依据实测决定是否值得另开优化，不自动扩大到四形状或 LLM。

## 接口与范围

- 平台复用固定 T17 的 RV64/lp64d/VLEN128、两槽 O2＋H1 硬件；时钟、复位、II=1、首响应2拍的硬件合同不变。正常 NEMU、flash、官方 AM 及硬件输入只读，运行前后核对原身份。
- `caller_full(context)` 接收独立行优先 `int8_t A[8][32]`、`int8_t x[32]`、紧密 `int32_t y[8]`、16字节对齐工作区和内核函数指针。缓冲区互不重叠且完整有效；VS已启用。它执行288字节打包、内核及8个INT32结果提取。
- 主比较双方调用同一个 C 函数、同一计时包装和同一内存地址，只改变函数指针。内核是已经合格的 `config_reuse_gemv_8x32_reuse_vdot/rvv`；重编后的完整对象必须等于原合格对象，最终 ELF 的全部16个公共leaf逐字节相等。
- 工作区保留8个16字节结果槽，低32位有符号结果，高96位全零，三处边界guard；A/x/y各有独立guard。窗口外逐字节检查输入、打包、完整槽、紧密y以及VL/vtype/vstart/vcsr。未使用区域同样检查。
- `demo.c` 保留文档原栈版代码，各数据集真实执行一次并检查紧密结果、输入和外部边界；不读取已结束生命周期的局部对象，不为其给出周期结论。全槽内存检查属于独立workspace路径，二者不混称。

## 主窗口与诊断

单ELF三数据集，每个范围六轮AB/BA配对：首次、预热、四次正式。范围为 `full`、`pack`、`core`、`extract`，共144个窗口，其中96正式窗口；主指标full共24正式窗口，每方法12个。第一次不是清空缓存后的冷缓存。独立重放比较所有窗口，不重复计入均值。

`full` 是未插入阶段计数器的完整workspace调用窗。三个阶段分别用相同数据、地址和内核指针做独立诊断：core的打包、extract的正确槽准备在其窗口外；不同准备及边界改变上下文，因此**三个诊断数不能相加当作full，不相减制造精确开销归因**。不扣空窗口开销，不把宿主时间当处理器周期。未修改R5稳定默认。

pack/extract 的两种method标签实际执行完全相同代码且不调用内核；其差值只作为运行顺序/上下文对照，不能解释成vdot收益。通过 `make --trace` 保存真实命令，逐个检查main/caller/demo三个独立C编译单元的目标ISA、优化与禁止特化参数；不修改官方Makefile。

计时沿用固定实现的 `fence/START/instret/fence/cycle/fence/调用/fence/cycle/fence/instret/fence/STOP`。普通C会覆盖a/t寄存器，因此计时包装保护s寄存器，在对应fence后保存begin计数；双方相同的保存、参数准备、调用/返回计入主窗口。每个调用点栈16字节对齐。

沿用原计数器解析/核验函数，保持四条计数器机器字、PC/ROB身份、采样值与退休值、前后fence、全核tick和instret一致检查；只在私有模块将原路径解析替换为本caller的独立有限控制流执行。实际C关闭自动向量化、LTO/IPA特化与库模式识别，以无压缩RV64GV编码限制检查范围。启动/AM库可保留其已合格编码。

路径检查器从ELF、固定指针和实际输入独立算出有限路径，支持本编译产物的标量寻址/循环/调用；不从DUT日志反推期望路径。vector写入值在路径分析中标记未知，不允许未知值控制分支；向量算术由固定leaf身份、独立标量oracle、全槽检查和实时DiffTest验证。检查288字节打包读写覆盖、32字节结果写入、128字节向量输出、调用/返回与栈平衡。压缩ROB条目不得跨branch/call/ret/marker/counter。

所有正常运行复用完整O2状态机，关闭时不能有pending/unfinished事务；每full/core vdot窗口32次真实退休，RVV与pack/extract窗口0次。包括三个栈示例在内，每正常进程预期1248次vdot提交。负控绑定新ELF实际首条vdot，vd0/bit100/`0x0388000b`，要求唯一差分失败与预期exit1，之后同BIN正常参考恢复。

## 资源、证据与交付

构建最多四核，性能EMU串行，禁止与同机重构建竞争。使用新的独立输出；失败/中断不隐式续跑。保存源快照、GNU命令与产物、实际运行回执、原始stdout/stderr、输入清单、负控和全部窗口。归档从原文复算，离线复算不声称重新核验物理EMU或人工验收。

该实验给出固定GEMV消费入口的运行与周期证据；不声称完整产品/LLM、新机器安装、人工ACK、全赛题通过或新增ASIC PPA。
