## 六例结果

各例都用独立标量计算核对低 32 位，检查高 96 位为零，并检查指令前的 VL、`vtype=0xc0`、`vstart=0`。寄存器关系与指令编码由实际 ELF 反汇编核对。

| 例 | 指令 / VL | 主要覆盖 | 实际低 32 位 | 结果 |
| --- | --- | --- | --- | --- |
| 0 | dot8 / 8 | 低 8 元素为零，高 8 元素不参与 | `00000000` | PASS |
| 1 | dot16 / 16 | 高 8 元素贡献，vd=vs1 | `00020000` | PASS |
| 2 | dot16 / 16 | 两源全部 -128，正端点，vd=v0 | `00040000` | PASS |
| 3 | dot16 / 16 | -128 × 127，负端点，vd=vs2 | `fffc0800` | PASS |
| 4 | dot16 / 16 | 混合有符号自乘，vd=vs1=vs2=v0 | `0000fe28` | PASS |
| 5 | dot8 / 8 | dot16 后恢复旧 dot8，有符号负值 | `fffe0400` | PASS |

实际日志明确加载固定 feature1 reference 并启用 DiffTest，随后输出 `cases=6 dot8=2 dot16=4 failures=0` 和 `HIT GOOD TRAP`。新生成 `diffstate.h` 与 reference 固定头的 SHA 相同；八个架构状态类型块及寄存器复制布局检查通过，布局跨度为 1,400 字节。动态调用的可用性由随后这一次真实整核差分限定。
