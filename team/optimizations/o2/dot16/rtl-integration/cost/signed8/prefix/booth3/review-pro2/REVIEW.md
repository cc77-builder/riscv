# Booth P3：一次寄存边界取舍的独立审查

## 决策

**有条件支持唯一一个 P3 局部点。** 已确认当前最坏 I2R 的保存目标就是拟移动末层的 carry 输出，因而这不是仅凭“少一层”提出的重排。建议用它回答：现有 Booth 的面积收益，能否转化为不恶化原 prefix 最坏 STA 的可选替代。这里没有支持 >10% 应用提速的证据，也不建议继续展开 P4/P5、分组或 mapper 参数矩阵。

R 仍负 slack，约 139 ps 的 arrival 差不是可用的正时序余量。建议继续的依据是明确瓶颈归因和已有局部流程的低试验成本，而非承诺 P3 会成功。

## 2. 为什么 P3 确实作用到当前瓶颈

从同一映射产物读取 DFF 实例连接：

- f1 I2R 终点 `_17980_` 的 Q 为 `dut.pRows_0_0[10]`。
- f0 I2R 终点 `_12383_` 的 Q 也是 `dut.pRows_0_0[10]`。
- 两 feature 的实际生成 `VDotCarrySaveRows.sv` 都是 81277 B、SHA `58dfeae9ec39cdc18e398dded21cd17e269706c62147a4e324901b859ca2752b`；其 `row0[10]=c_7_9_0`，属于第七编号、也就是最后一个有工作压缩层。

因此末层移动能改变当前临界保存目标的组合计算，满足开展一次边界试验的实质前提。这不等于已经隔离出该末层在当前 mapped 路径上的准确耗时；ABC 可以重写逻辑，新保存节点与新的最坏路径都会变化。

输入端的工作不会一并消失：f1 I2R 从 `src1[21]` 出发，前段 `_09982_/Z` 是一个 **128.415 ps** 的 XOR 输出弧，驱动 cap **17.489012 fF**。它对应的 Booth 选择/扇出代价仍需承担，不能把当前 I2R 都归于最后 CSA。

## 3. R 的预算很紧，不能搬用 arrival 差

f1 当前两端 required time 分别是 I2R 0.926182 ns、R2R 0.921503 ns。arrival 差为 139.462 ps，而违例程度差为 **134.782 ps**，二者均不是正 setup 余量。

定义新实现相对当前 Booth 的 I2R slack 改善为 dI、R2R slack 损失为 dR（单位 ps）。仅考虑这两类路径时，新最坏值为：

`min(−254.728+dI, −119.946−dR)`。

若目标是至少不差于原 prefix f1 的最坏 −238.006 ps，便需要 dI≥16.722、dR≤118.060；这是比较条件，不是给新候选预测或增加验收门槛。其他已有路径类别仍按原合同比较。

当前 R2R 从 `pRows_0_0[3]` 到 `rPacket_res_data[18]`，前段已有五级 XOR/XNOR；最前两弧合计 **115.700 ps**。新增 3→2 的 sum 支路可能多两个 XOR 逻辑层，说明其代价足以接近上述比较空间。不能直接把 115.700 ps 加到新 arrival：新负载、转换、引脚、映射和最坏路径都未确定。

f0 的当前最坏 R2R 从 `rPacket_ctrl_robIdx_value[3]` 出发，经 ready/enable 网络至 `pRows_0_1[9]`，是控制保持路径。其 +17.123 ps 不能当作新增算术 CSA 的可用余量；额外行的捕获扇出也可能影响这条路径。

## 4. 简单的结构安排与偏置反例

按冻结源的固定调度，停在 limit3 时每半累计 272FA/19HA、53 个位位置、最大七层 compressor 依赖；当前 limit2 为 288FA/20HA、37 个位置、八层。因此原末轮为 **16FA＋1HA**。这些是源结构统计，不是实际映射门数或延迟。

三行截面 col0…16 各三位、col17/18 各一位、col19 空。全宽三输入压缩不一定逐门等同旧稀疏末轮，例如原 col0 为 HA 加第三位直通，而全宽压缩可成为 FA。因此不能声称总组合门数完全不变。

最简单的后级安排是：feature0 三条19位行先做一次模2^19的3→2，再用原 Finish19；feature1 两半各三条20位行先并行3→2，再用原四输入 Finish20。无需先对每半作 carry-propagate 求和，也无需扩展中间算术到21/22位。原 Finish 本体和已有证明可以继续作为组成部分；新增压缩与实际连线仍须建立新候选的整体资格。

**不能把“正常生成截面 col19 为空”硬编码到 R。** 当前 feature1 dot8 要注入高半 biased zero，三行可为 `(2^19,0,0)`。如果精确照搬旧稀疏末轮、却把 col19 仍固定成0，会丢失这项偏置；低半真值0将错误恢复为 −524288。全宽3→2会正确传递该位。

拓扑无关条件是每半三行同宽模和等于 `S8+2^19`，dot8 高半模和等于 `2^19`；后续每一步保存同宽模和。feature0 取 low19。所有三行与 pCtrl/pPerf 在同一 `in.fire` 捕获，R 只读旧 P，沿用 pValid/rValid/move/kill/reset 事件关系，便可保持 E2/II1；不需要额外槽位或晚到模式旁路。

## 5. 面积机会和停止条件

名义 P 数据增加 f1 40bit、f0 19bit；固定截面的非空位置仅每半增加16，实际 DFF 仍取决于常量和模式路径。实读同一冻结库得到 DFF_X1=4.522、MUX2_X1=1.862；假定40位各增加一 DFF 与一个保持 MUX，面积量级为 **255.36**。这只是解释原774.858节省未必全部耗尽，既不是预测面积，也未包含时钟/使能缓冲及全局重新映射的变化。

这个单点应比较与两份冻结结果相同条件下的实际面积、全路径 slack、寄存数和原局部正确性证据。如果只是把违例搬到 R，或没有得到目标相关的面积/最坏时序组合，就保留原 prefix 与本次 Booth Pareto 结果，结束此分支。即使局部更好，也不自动取得父级、整核、应用提速或全核频率资格。
