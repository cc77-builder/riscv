# B0/H1 同镜像周期不退化检查

2026-10-21，用户已明确授权本轮检查。两版都为 O2 两槽弹性 FU；B0 保存 128 位结果，H1 保存低 32 位并在公开输出补零。只在本地执行，正式报告后置，不推送 GitHub。

复用已验收 B0 与 H1 仿真器，必须先核对固定构建 pins、429 项 Git 源码、21,236 项依赖、实际生成产物、编译命令和七类工具版本。B0 构建 pins 中旧 emu_path 保留原样；实际运行的是完整保留目录中的同 SHA 二进制。源码额外差异仅为独立 O4 测试构建入口；生成 RTL 的 Git 标识、顶层注释和输入型日志模块差异单独记录，不能宣称全设计形式等价。共同辅助文件逐字节相同；同一 O2/T13 观察配置、MinimalConfig、单核、单线程、128MB、seed=1、正常 NEMU 与 flash。

使用原 16 个冻结镜像（1 校准、3 功能、12 性能），保持 208 份软件来源/数据/ELF/bin 原字节。先校准和功能，再四场景 single1/chain256/batch128/stream64，各三数据集、四轮正式测量；保留 first/warmup。每版额外重放 dataset0 batch 两次，共 36 项新运行、478 个校验窗口、192 个正式窗口；历史周期不进入统计。跨镜像最多两项并行，同镜像两版顺序交替。每项 120 分钟、2 百万周期上限。

保持原统一窗口、全 128 位结果、允许 scratch 范围、CSR/哨兵、退休指令、全局计数、真实 DiffTest/GOOD TRAP/致命错误和 O2 生命周期/排空门禁。不修改原检查器或黄金数据。运行前后固定输入与工具散列，离线重新解析原始 stdout/stderr 和真实退出码。

不退化判据预先固定：96 对正式窗口（包含 vdot 和 RVV）逐键配对，工作量、镜像、seq 与退休指令一致；H1 任意正式窗口比 B0 多一个周期也单独标记，不使用 2% 容差掩盖。分别报告每场景每方法均值/范围、逐窗口差值、相同窗口数量、退化窗口清单；不把平均值相同当作所有窗口相同。性能测量完成和不退化结论分开记录。4 次重放只核对确定性，不增加样本数。加速比用各版本次实测 RVV/vdot 周期和，不扣计时开销、不用宿主耗时计算。

本轮仅检查上述微基准，不能扩展为 GEMV 应用、Fmax、功耗或全部工作负载不退化。原面积与 STA 取舍不变；不改默认开关、旧 R0 锁、旧封存证据，不自动开展 R2/R4 或代签团队 ACK。失败和未满足项原样保留。
