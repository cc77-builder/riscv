## 命题与判定

1. 目标是 !reset && !divBusy => intReady && fpReady。divBusy 是寄存的事务占用位；不能偷换为含 !divReady 的组合 elasticDivOccupied，后者会让结论成为定义恒真。
2. 不在模型中假设目标结论。不约束完成延迟为某个测试值；安全性质使用包含全部真实转移的保守控制抽象。必须覆盖各浮点 lane 的 DIV/SQRT 状态、输出汇合、反压、复位边沿、ROB 身份和取消优先级。
3. 区分有效初始化后归纳成立、实际全核复位合同已核实、无条件任意复位成立。不存在有效复位到子单元时不能假设其初值。发现合法反例则保存，并停止该 RTL 写法；不得静默约束掉反例。
4. 至少加入会破坏初始化／取消／完成同步的模型变异，验证检查器可拒绝。模型通过只证明声明的控制抽象；源码映射由明确行号、哈希和独立复核支撑，不能冒称全 RTL 形式等价或真实 SQRT 数值仿真。
