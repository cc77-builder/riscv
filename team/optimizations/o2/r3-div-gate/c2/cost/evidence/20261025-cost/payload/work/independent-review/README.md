# C2 同约束成本筛选独立复核

本目录由独立 Agent 只读复核生产源码、旧证据和新成本输出。未修改 RTL、旧证据、全局工具或主文档，未运行综合/STA/全核，也未写 GitHub。screen_c2.py 只交给根 Agent 审查并执行。

## 固定合同

正确性基线为 0f12df675378556670afd0dd2153f47fcb330610，C2 为 6704ce3502a7235cdb81697638c01ed23f6914f6。C2 包含已否决 C1 的 busy+owner 结构及新的无 ready 启动项，必须对 0f 独立筛选，不能当成采用 C1。

- 五档为 nominal 1ns/5fF、period050 0.5ns/5fF、period200 2ns/5fF、load001 1ns/1fF、load020 1ns/20fF。
- 45 项为每档 r2r、i2r、vdot_r2r、vdot_i2r、vdot_r2o、ready 及浮点/整数/VDot 三个 ICG.E。最差 arrival 不得超过基线 101%；基线非负的门控 slack 还须保持非负。
- 独立门禁：nominal 全部 busy、owner 及任何仍保留保持状态 D 端最差 arrival ≤ 1.737526ns；基线控制最差须重现 1.930584ns。
- 完整父级面积 ≤ 284614.946 × 1.001 = 284899.560946（Nangate45 库面积单位），未知 cell 为 0；必须是相同端口、库、映射参数和真实完整父级边界，三个 ICG 均参与。
- 使用同一 Nangate45 typical、ABC -D1000、BUF_X1/5fF 驱动、线负载 5K_hvratio_1_1、理想时钟、0.05ns uncertainty/transition、0.1ns 输入/输出延迟以及 testEnable=0。不得新设 false path 或缩减查询端点。
- 综合/STA 工具返回成功与筛选通过分别判断；原参考 1ns 整体未收敛，内部筛选通过仍不等于完成物理实现或整核 Fmax 认证。

## 脚本与验证

screen_c2.freeze.json 固定最终筛选驱动哈希。驱动完整沿用旧合同，仅替换 C2 身份、资格入口与路径；增加原文前缀和 45 项唯一性检查。最初草案的 Python 换行转义在 AST 检查修正，随后原只读 preflight 识别一项 command-origin；均在执行 EDA 之前修正，记录保留。

preflight-fixed.json 已核验 C2 375 项封存 payload、374 个实际来源文件和 1 个 git format-patch 命令输出；0f 的 143 个旧成本文件与原封存一致。

generated-production-audit.json 记录新成本 RTL 与 0f 的逐文件哈希。56 个文件集合相同，54 个逐字节相同，包含完整顶层和所有 VDot/DIV/SQRT 算术模块；ExeUnit.sv 为预期逻辑差异。LogPerfEndpoint.sv 只在 SYNTHESIS 禁用的打印区块内调整语句顺序，实际综合文本相同。未发现补充观察器或测试顶层混入。

audit_cost.py 不调用任何外部工具，仅从 Liberty、实际映射网表、语义 DFF/ICG 绑定与原始 STA 报告独立复算面积、45 项以及控制 D 门禁，核对主筛选决定。其 66 项内存观察数据破坏检查已通过；这是审计拒错自测，不是 RTL 变异、形式证明或芯片测试。已用 C1 的旧原文输出自检，准确重现 30/45 项通过、15 项拒绝及 C1 总拒绝；见 selftest-c1-reference/。这只是审计器参考验证，不能转记为 C2 成绩。
