# 正式工程图源文件

本目录保留可编辑SVG、制图脚本、冻结证据摘录及实际导出记录。报告采用的文件以父目录的 `selected-diagrams.json` 为准；源目录内的同名早期PDF不等于最终入稿版本。

`pdf-textpath-correction/` 保存 S1-01 与 S3-01 的最终转轮廓PDF及对应可编辑SVG。原导出PDF存在已记录的CFF字符映射问题，保留用于追溯，不被选择入稿。其他最终SVG图也采用文字转轮廓PDF，避免依赖阅读端字体；图中文字仍可在SVG中编辑。

`precise-core/` 对五张已经核对的精确图仅调整颜色，几何、标签与数值保持不变。该目录的原始输入及差异核验一并保留。

重新编译报告直接使用经过SHA-256绑定的最终PDF，无需安装Inkscape或重新绘图。若修改SVG并重新导出，应安装脚本指定的字体及绘图工具，重新核对字体、布局和图意，并更新选择清单中的SHA-256。图的历史工程证据不会因重新绘图而成为新的运行结果。
