# S3-01 精确结构对照稿

本稿用于比较技术结构图与插画两条表达路线，尚未获得人工最终审美认可。图稿为确定性 SVG；PDF/PNG 是该 SVG 的实际导出，没有运行 RTL 构建、仿真或工程回归。

## 图面与复核

成稿 160 × 122 mm，普通文字最小 11.6220 pt，模型名 12.4724 pt。白底、细线，蓝色区分 DUT、青色区分参考模型；PDF 实际嵌入 Noto Sans CJK SC 常规与粗体。若换字体重新导出，需检查新排版。

左侧为8个乘积及4→2→1组合归约；右侧为从零开始的逐项软件乘加回环。D/R 仅代表两侧计算结果。算术结果只连到各自向量状态的低32位，另外的 CSR 和异常字段属于整个模型。底部三组比较各接一份 DUT、一份 REF 同类状态，问号表示中性的比较操作，不预置成功结果。

`diagram-structure.json` 保留26个具名对象、47条语义关系，包含8个RTL乘法、7个归约加法及三组两侧字段配对。`render-qa.json` 记录实际 PDF 尺寸、字体、文字边界与最终目视复核；首轮三处间距问题和原图保留在 `first-render/`，当前选用文件在本目录顶层。

## 必须保留的外部图注

同一程序与初始状态由 RTL 与 NEMU 独立执行。左侧示意合法 VDot 输入的八路有符号乘积与组合归约，右侧示意 C 参考模型的逐项乘加，不表示内部周期对齐，也不把树层数作为流水级。D/R 是两侧结果符号，完整向量结果高96位为零、低32位为和的二补码；问号表示比较操作，不表示已通过测试。向量 CSR 和异常信息来自各模型整体架构状态，在对应架构提交处进行同类比较。图中省略整核控制、非法输入分支及 DiffTest 内部调度，不将 FU 响应等同于退休。
