# Build11 整合包核验

本包包含当前 LaTeX、全部编译输入、四份实际编译的 PDF、图件索引与核验记录。

- 110 个原生编译输入逐项匹配冻结 SHA256；编译前后身份一致。
- 四份 PDF 分别为 65、18、23、26 页，已核验完整文件 SHA256。
- 38 组编号技术图及 22 张概念图均已记录，未发现缺图、缺字、未定义引用或越界排版。
- v2 逐图视觉审查与 v3 增量审查的适用文件分别保留；61 页逐像素一致，4 个修改页已单独复核。
- 失败的首轮编译和后续两轮编译元数据均保留，便于追溯百分号转义与排版修订。

解压后从根目录执行 `python -X utf8 build.py`。需要 Python 3.9+ 与完整 TeX Live（推荐 2026，含 XeLaTeX、ctex、Fandol、TeX Gyre），编译不访问网络。各测量的版本与适用范围见正文；该整包校验不新增硬件或性能结论。

`DELIVERY_MANIFEST.json` 给出本包各成员（不含其自身）的字节数及 SHA256。Git 发布与邮件实际发送在完成后另行记录，不能由本地整包状态推断。
