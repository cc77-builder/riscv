## 报告结构与编辑入口

三个阶段分别围绕环境验证与向量执行过程、向量点积设计与功能验证、协同仿真与性能分析展开。章节围绕实验过程和结果组织，详细版本、复现资料及原始日志集中在相应章末。章节编号最多为三级，例如 `1.2.3`。

当前正文由以下文件共同生成：

| 文件 | 作用 |
| --- | --- |
| `content/overview-stageN.tex` | 主要过程、设计和结果的 TeX 内容块 |
| `content/narrative-stageN.md` | 原理、方法与分析内容块 |
| `content/technical-stageN.json` | 技术细节、接口及结果内容块 |
| `content/structure-stageN.json` | 当前报告标题、引言、章节顺序、内容块选择、内联补充文字和图位 |
| `figures/placement.json` | 正式图的稳定 ID、图题、简短说明、高度、来源及适用范围 |
| `sections/screenshots-stageN.tex` | 补充截图定义，由结构文件放入对应章节 |

`expand_reports.py` 转换文字源，调用 `report_structure.py` 将内容切分为命名块并按结构 JSON 组装，再由 `report_layout.py` 应用统一排版，生成 `sections/stageN.tex`。每个来源块在结构中使用一次或列入 `omitted`；正式图及补充图按结构指定位置插入。阶段一的完整原始操作日志由生成器另行追加。

修改论述时编辑相应内容源；调整章节、图位或内联补文时编辑结构 JSON。块 ID 按源标题顺序生成，增删或调整源标题后需同步更新结构映射。`sections/stageN.tex` 为生成文件。`content/baseline/` 和 `content/evidence-stageN.json` 保留上游原文，不随现行正文编辑覆盖。

A4，四边25 mm，正文12 pt。正文中文使用宋体，英文及代码/日志使用 Times New Roman。八张源数据、事件与启动指令图的生成器使用Microsoft YaHei；S3-05采用Noto Sans CJK SC；精确SVG按独立记录使用Noto Sans CJK SC等实际字体，截图分图标题使用宋体。精确图以约160 mm原宽、至少11 pt文字绘制，最终缩放以实际正文页检查为准。SVG保留可编辑文字；为处理CFF数字映射问题而导出的文字轮廓PDF保留字形，不将轮廓路径称为可搜索文本或嵌入字体。字体和字号依据可编辑源、实际绘图环境及输出记录核对，不凭生图提示词认定。系统字体由排版器调用，工程不分发字体文件。

## 编译方法

入口为 `main.tex`、`stage1.tex`、`stage2.tex`、`stage3.tex`，公共模板为 `preamble.tex`。安装 XeLaTeX、SimSun 和 Times New Roman 后，从本目录运行：

```bash
python -X utf8 expand_reports.py
python -X utf8 build.py --output-dir <独立输出目录>
```

`build.py` 默认依次编译合订本和三个分册，每份三遍；`--compiler` 可指定 XeLaTeX，`--documents` 可选择文档。分别启动文档编译时，为每个任务使用独立输出目录。实际交付 PDF 放在 `output/`，中间编译产物与本次日志保存在指定输出目录。

图片按同名 PDF、PNG、JPG 顺序加载。正文生成后再编译，图形发生变化时先完成相应图件重建。
