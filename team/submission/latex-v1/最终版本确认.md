## 编译与交接

解压后运行 `python -X utf8 build.py` 可生成四份 PDF；也可通过 `--documents main` 只生成合订本。构建需要 Python 3.9 或更新版本及包含 XeLaTeX、ctex、Fandol、TeX Gyre 的完整 TeX Live，推荐 TeX Live 2026。开放字体、全部直接引用图片和所需摘录随源包提供，编译过程无需网络。具体命令见 `README.md`。

正式队伍名称、人员分工、学校、指导教师和赛事提交信息按人工确认填写；历史日志中的身份保持原样。最终 Git 发布与邮件发送使用各自的实际回执登记，本文件确认报告内容和编译制品的身份。
