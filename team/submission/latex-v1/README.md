## 文档与重编译

入口为main.tex、stage1.tex、stage2.tex、stage3.tex；公共模板为preamble.tex。最终页数：合订本110页，第一阶段33页，第二阶段41页，第三阶段39页。2026-11-05完成复核；当前页数及验证见[版式校验](qa/pdf-inspection.json)，交付PDF位于output目录。

三个单册的正文汉字数依次为10,355、17,916、17,538，达到第一阶段至少10,000字、第二及第三阶段各至少17,000字的要求。计数使用最终PDF文本，剔除封面、目录及页面上方页眉、下方页脚；具体起始页和规则记录在版式校验中。重复论述已合并，保留实验数字、比较条件及必要推导，不增加未经运行的实验成绩。

安装XeLaTeX与有权使用的SimSun、Times New Roman字体后：

```bash
python -X utf8 expand_reports.py
python -X utf8 build.py
```

build.py可通过--compiler指定XeLaTeX，通过--output-dir指定独立输出目录，每份编译三遍。仓库不分发字体文件。

正文由content中的原材料、expand_reports.py、report_layout.py及figures/placement.json生成。修改排版应修改模板或生成器，再重新生成；不直接修改生成的sections/stage*.tex，以免下次覆盖。图像仍按同名PDF、PNG、JPG顺序加载。
