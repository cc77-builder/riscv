## 2. 当前架构与改动边界

- 当前仓库根是 XiangShan，处理器实现位于 `src/main/scala/xiangshan/`；`team/` 保存团队规格、程序、脚本与证据。

### 3.1 建议保留的原型约定

下表是初步评审建议，尚未形成团队签字结论。

| 项目 | 初步意见 | 理由及验证边界 |

| 低 8 项 signed int8、从零累加 | 建议保留 | 数学模型明确；高 64 位不参与，需用 L02 验证 |
| 32 位精确结果，高 96 位清零 | 建议保留为内部候选 | 数值范围可容纳；不能从 SEW=8 推导为普通 8 位结果，仍需 Q02/Q03 答复 |

### 3.2 本次实际完成的检查

在当前 Windows 工作区以临时 Python 程序重新计算，全部通过：

| 检查 | 覆盖与结果 |
| --- | --- |
| D00～D10 | 11 组十进制和低 32 位补码期望均一致 |
| 单项乘积 | 穷举 65,536 组 signed int8，极值为 -16256 / 16384 |
| 八项累加 | 可达范围 -130048～131072；18 位有符号数不足，至少 19 位 |
| 候选编码 | 32,768 种 vd/vs1/vs2 组合均匹配且字段还原一致 |
| BitPat | 与 `MATCH_VDOT=0x0200000b`、`MASK_VDOT=0xfe00707f` 一致 |
| 固定位拒绝 | 分别翻转 mask 中的 17 个固定位，均不再匹配 |
| 示例机器字 | v10/v8/v9 编码为 `0x0284850b`，小端字节为 `0b 85 84 02` |
