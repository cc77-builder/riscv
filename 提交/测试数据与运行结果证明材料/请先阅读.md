# 测试数据与运行结果

香山昆明湖 V2 自定义向量点积指令（vdot.vv）三阶段报告的测试数据、运行结果与原始记录。

**先打开 [测试数据与运行结果证明材料.pdf](测试数据与运行结果证明材料.pdf)。** 它按报告的三个阶段列出每项测试的输入、运行环境、结果和原始记录位置，第 2 节是报告结论与原始记录的对照表。文中的文件路径都相对于本文件夹，请解压后保持目录结构。

## 目录

| 位置 | 内容 |
| --- | --- |
| `测试数据与运行结果证明材料.pdf` | 主文档 |
| `evidence/` | 原始日志、结果文件、波形和截图，保持原始字节；编号含义见主文档附录 B |
| `data/` | 从原始记录整理出的逐窗口数据、事件时间线、证据索引和版本核查 |
| `figures/` | 主文档中的数据图 |
| `reference/submission/logs/` | 发布提交中的 7 卷原始日志归档及读取工具 |
| `reference/team/models/vdot/data/` | 完整测试向量（定向、随机、状态、smoke） |
| `tools/` | 校验、数据整理和绘图脚本 |
| `源文件/` | 主文档的 LaTeX 源文件 |

## 校验

在本文件夹执行（Python 3.9 或更新版本，只用标准库）：

```bash
python tools/verify_package.py
```

脚本逐个核对全部文件的大小和 SHA-256，并把基础测试日志和全核波形文件与原始运行记录中登记的 SHA-256 对比。日志归档可另用 `python reference/submission/logs/read_log.py verify` 校验。

## 重新生成

- 数据图：`python tools/draw_figures.py`（需要 matplotlib、numpy，以及 Times New Roman 和 Noto Sans SC 字体）。
- 主文档：在 `源文件/` 中用 `xelatex 证明材料.tex` 编译三遍，字体与三阶段报告相同，安装完整 TeX Live 即可。
- 更换或补入文件后，执行 `python tools/verify_package.py --update` 更新校验清单。

完整代码在团队仓库的 [`release/cie2026-v1`](https://github.com/cc77-builder/riscv/tree/release/cie2026-v1) 分支，复现步骤见 [提交/复现操作步骤.pdf](../复现操作步骤.pdf)。生产源码与受测硬件 `0f12df67` 相同（`src` 树 `78a0c938`）。
