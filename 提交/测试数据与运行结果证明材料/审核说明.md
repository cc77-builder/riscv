## 打开全核波形

全核 `vdot-positive.fst` 以 Git LFS 保存，网页下载的 ZIP 中只有 LFS 指针，请用 Git 克隆后拉取。在仓库根目录执行：

```bash
git lfs pull
cd '提交/测试数据与运行结果证明材料'
python3 tools/verify_package.py
gtkwave evidence/W01_vdot-wave-20261105/vdot-positive.fst vdot-positive-portable.gtkw
```

`vdot-positive-portable.gtkw` 使用相对路径和完整 FST 的层级名称，包含 24 个信号，时间坐标、信号顺序、显示格式和标记与原始视图相同。原始视图 `evidence/W01_vdot-wave-20261105/vdot-positive.gtkw` 按原字节保留，它对应当时导出的裁剪 VCD，使用原机器的绝对路径。
